# Insurance Cost Analysis

A basic data analysis mini project using Python and the Medical Insurance dataset.

## Objective

To explore the insurance dataset and understand the factors related to medical insurance charges.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Analysis Performed

- Data exploration
- Data cleaning
- Duplicate handling
- Categorical encoding
- Feature engineering
- Data visualization
- Standard scaling
- Pearson correlation analysis

## Dataset

The dataset contains information about:

- Age
- Sex
- BMI
- Children
- Smoker
- Region
- Insurance Charges

## Project Type

Basic Data Analysis Mini Project
