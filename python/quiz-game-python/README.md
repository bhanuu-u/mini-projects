# 🎯 Python Quiz Game

A terminal-based General Knowledge Quiz Game built using Python.

This project provides an interactive quiz experience with animated text, a progress bar, score tracking, and performance feedback. It demonstrates the use of Python fundamentals such as functions, lists, dictionaries, loops, conditionals, and user input while creating an engaging command-line application.

---

## ✨ Features

- 🎮 Interactive terminal quiz
- ⏳ Animated typing effect
- 📊 Progress bar for each question
- 📈 Live score tracking
- ✅ Instant answer validation
- 🏆 Performance-based feedback
- 🔄 Play again option
- 🖥️ Cross-platform screen clearing

---

## 🛠️ Technologies Used

- Python 3
- Built-in modules:
  - `time`
  - `os`


