# ⌨️ Typing Speed Test

A simple command-line Typing Speed Test built using Python. This project measures your typing speed, accuracy, and mistakes while helping you improve your typing skills.

---

## ✨ Features

- 🎲 Random sentence selection
- ⏱️ Calculates typing time
- 🚀 Words Per Minute (WPM)
- 🎯 Accuracy percentage
- ❌ Mistake counter
- ⏳ 3-second countdown before the test
- 💻 Clean terminal interface

---

## ▶️ How to Run

1. Download or clone this project.
2. Open the project folder in VS Code.
3. Run `typing_speed_test.py`.
