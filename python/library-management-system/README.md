# Library Management System

A Python-based Library Management System built to practice Object-Oriented Programming (OOP) and GUI development.

The project allows users to manage books through a graphical interface. Book data is stored in a JSON file so that changes remain saved even after closing the application.

## Features

- Display all books
- Search for books
- Add new books
- Remove books
- Borrow books
- Return books
- Save and load book data using JSON
- Persistent book availability
- Tkinter graphical user interface
- Scrollable book list
- Input validation and error messages

## Technologies Used

- Python
- Object-Oriented Programming
- Tkinter
- JSON
