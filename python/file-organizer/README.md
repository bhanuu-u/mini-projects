# 📂 File Organizer

A Python utility that automatically organizes files into folders based on their file extensions.

## Features

- Organizes Images
- Organizes Documents
- Organizes Audio
- Organizes Videos
- Organizes Archives
- Organizes Executables
- Organizes Python Scripts
- Automatically creates folders
- Skips unknown file types

## Technologies Used

- Python
- os
- shutil

## How to Run

```bash
python main.py
```

Place `main.py` in the folder you want to organize and run it.
