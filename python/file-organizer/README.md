# 📂 File Organizer

A Python utility that automatically organizes files into categorized folders based on their file extensions. This project helps keep directories clean by sorting files into folders such as Images, Documents, Videos, Audio, Archives, and more.

---

## ✨ Features

- 📸 Organizes image files
- 📄 Organizes document files
- 🎵 Organizes audio files
- 🎬 Organizes video files
- 🗜️ Organizes archive files
- 🐍 Organizes Python scripts
- ⚙️ Organizes executable files
- 📁 Automatically creates folders if they don't exist
- 🚫 Skips unsupported file types safely
- ⚡ Fast and lightweight

---

## 📁 Supported Categories

| Category | File Extensions |
|----------|-----------------|
| Images | `.jpg`, `.jpeg`, `.png`, `.gif`, `.bmp`, `.webp` |
| Documents | `.pdf`, `.docx`, `.txt`, `.xlsx`, `.pptx`, `.csv` |
| Audio | `.mp3`, `.wav`, `.aac` |
| Videos | `.mp4`, `.avi`, `.mkv`, `.mov` |
| Archives | `.zip`, `.rar`, `.7z` |
| Python | `.py` |
| Executables | `.exe`, `.msi` |
