# Real Estate Market Analysis

An exploratory data analysis project using Python and Pandas to analyze
real-estate market data and identify pricing patterns, locality trends,
property characteristics, and builder pricing.

## 🛠️ Technologies Used

- Python
- Pandas
- Seaborn
- Matplotlib

## 📊 Analysis Performed

The project answers questions such as:

1. Which is the costliest property in the dataset?
2. Which locality has the highest average price?
3. Which locality has the highest average rate per square foot?
4. Do ready-to-move properties cost more than under-construction properties?
5. Do RERA-approved properties command a price premium?
6. How does area impact property price?
7. Which BHK configuration has the highest average rate per square foot?
8. Which property type is the most expensive?
9. Which builders have the highest average rate per square foot?
10. Are larger homes more expensive per square foot?

## 🔍 Key Skills Demonstrated

- Data loading with Pandas
- Data cleaning
- Handling numerical and categorical data
- Removing duplicate records
- Type conversion
- Boolean mapping
- Data filtering
- GroupBy and aggregation
- Sorting and ranking
- Finding maximum values
- Exploratory data analysis
- Data visualization with Seaborn
